# 屏净 v0.1.0 · 安装与使用（安卓通用测试版）

## A. 怎样制作 APK？

目前提供 **Android Studio 工程**，不是成品 APK。Android Studio 打开根目录 → 等待 Gradle 同步 → Build → Build APK(s) → 从 `app/build/outputs/apk/debug/app-debug.apk` 获取安装包。

如果你不想配置本地环境：上传工程文件至 GitHub 仓库（保留 `.github/workflows/build-debug-apk.yml`），点击 Actions → Build Android debug APK → Run workflow，成功后从 Artifacts 获取 APK。该流程依赖 GitHub 的云端构建服务，需要正常联网与仓库权限。

如 IDE 询问 Gradle 版本，使用 8.13。Android Gradle Plugin 版本 8.13.2、Android API 35、JDK 17。

## B. 手机安装步骤

1. 手机允许当前文件管理器安装经你确认来源的 APK。
2. 安装并启动「屏净」。
3. 打开「自动跳广告总开关」。
4. 阅读授权说明，主动进入系统的无障碍服务设置，找到「屏净 · 自动跳广告」并开启。
5. 返回「屏净」，首页显示「防护运行中」后，再去测试某个普通 APP 的开屏广告。
6. 若不希望屏净操作某个 APP，进入「应用」页将其关闭。

**安卓 13+ 可能提示“出于安全考虑，此设置目前不可用”**：这属于安卓对部分非应用商店安装包的受限设置。请确认 APK 的可信来源，并查看该品牌系统关于“允许受限设置”的官方说明；不要为了测试取消无关安全保护。

## C. 品牌系统差异

| 手机品牌 | 可能需要检查的位置 |
|---|---|
| 小米 / Redmi / POCO | HyperOS/MIUI 无障碍、应用后台、节电策略 |
| 荣耀 | MagicOS 无障碍、应用启动管理、电池优化 |
| OPPO / 一加 / realme | ColorOS/OxygenOS 无障碍、自动启动、后台活动 |
| vivo / iQOO | OriginOS/Funtouch OS 无障碍、后台耗电管理 |
| 三星 | One UI 无障碍、后台使用限制/休眠应用 |
| 华为 | 仍兼容 Android APK 的 EMUI/HarmonyOS 版本；纯鸿蒙 HarmonyOS NEXT 不能直接安装此 APK |

不同版本名称、入口可能变化。**当前未完成上述品牌真机验证。**

## D. APP 内广告怎么关闭？

有“跳过 / Skip / 关闭广告 / 关闭此广告”等可访问按钮时，屏净会尝试自动触发按钮。对于自定义的具体关闭按钮，进入「应用」→ 找到相应 APP →「＋ 添加规则」→ 输入按钮文字。例如某 APP 弹窗上的按钮恰好写着“暂不需要”，可将“暂不需要”设为该 APP 专属规则。不要为“确认支付”“下载”等敏感按钮设置规则。

目前不支持屏幕图像识别，不会盲点角落的 X；如果按钮不可访问，就无法通过现有机制可靠识别。

## E. 常见故障

- 首页显示等待授权：检查系统“屏净 · 自动跳广告”服务是否启用。
- 完全没反应：确认总开关、应用独立开关、按钮文字是否在基础规则范围内。
- 有广告却没有规则：使用应用专属规则；图片按钮目前无法自动识别。
- 一段时间后失效：排查无障碍服务是否被系统关闭、后台节电设置。
- 误点按钮：第一时间关闭屏净总开关，关闭该应用独立开关，删除有关自定义规则。
- 想拦横幅、视频、广告请求：本版还没有网络过滤功能，不能完成此类任务。

## F. Windows 一键尝试构建

工程根目录有 `生成APK_Windows.bat`，可以双击调用旁边的 PowerShell 构建脚本。前提：电脑已安装 Android Studio 的 SDK Platform 35，并具有 JDK 17+；初次运行需要联网下载官方 Gradle 8.13 和 Android Gradle 插件。首次自动下载的 Gradle 会保存到工程内 `.build-tools` 目录。**当前环境无法运行 Windows 脚本，尚未验证一键构建流程。**
