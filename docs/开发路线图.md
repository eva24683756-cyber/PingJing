- 网络拦截与点击服务必须单独开关。一个安卓用户/配置通常不能同时使用两个 `VpnService` VPN，后续应与其他 VPN 的冲突给予明确提示。
- 不申请 root，不要求强制 ADB 授权。
- 如后续引入规则订阅，应提示来源和许可，禁止自动执行任意网络下载脚本。
- 如准备在 Google Play 上架，应先重新评估 Accessibility API 用途是否符合当时政策。必要时考虑其他分发渠道。
